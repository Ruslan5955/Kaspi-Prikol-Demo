# Kaspi Прикол — Android demo

Самостоятельная пародия с красно-белым оформлением. **Это не Kaspi.kz и не настоящий банк.** Все суммы вымышлены.

## Возможности
- Шуточный баланс 10 000 000 ₸.
- Анимация одобрения кредита.
- Создание локальных демо-переводов с именем и суммой.
- Демо-квитанция и история операций.
- Постоянные заметные предупреждения «ДЕМО · НЕ БАНК».

Переводы не отправляются, реальные счета и банковские данные не используются.

## Скачать APK без Android Studio
1. Открой вкладку **Actions** в этом репозитории.
2. Выбери **Build parody Android APK** и нажми **Run workflow** (или запусти workflow после первого коммита).
3. Дождись зелёной галочки и открой завершённый запуск.
4. Внизу в разделе **Artifacts** скачай `Kaspi-Prikol-Demo-APK`.
5. Распакуй ZIP и установи `app-debug.apk` на Android. Если нужно, разреши установку приложений из браузера/файлового менеджера.

APK собирается GitHub Actions; это исходный проект, не банковское приложение.
